# 🌦 Weather App

A modern responsive weather application built with React that fetches real-time weather data from an API. Users can search cities worldwide to view temperature, humidity, wind speed, and weather conditions instantly.

---

## ✨ Features

- 🌍 Search weather by city
- 🌡 Real-time temperature updates
- 💨 Wind speed and humidity display
- ☁ Dynamic weather conditions
- 📱 Fully responsive modern UI
- ⚡ Fast API-based weather fetching

---

## 🛠 Technologies Used

- React.js
- JavaScript
- CSS
- Weather API

---

## 🚀 Purpose

This project was built to improve frontend development skills and API integration knowledge while creating a clean and interactive user experience.
